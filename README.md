## 📖 About The Project

**VibeLab – Signals & Systems Laboratory** is a web-based project developed using TypeScript and modern frontend technologies.

The project is organized into modular components and dedicated signal-processing modules, providing a structured foundation for exploring concepts related to Signals and Systems through a digital laboratory environment.

The application follows a modular architecture that separates UI components, signal-processing logic, services, type definitions, and application views.

### 🎯 Project Objectives

- Develop a modern web-based Signals and Systems laboratory.
- Organize signal-processing logic into reusable modules.
- Build a modular and maintainable frontend architecture.
- Provide an accessible digital environment for learning and exploring Signals and Systems concepts.

---

## ✨ Key Highlights

- **TypeScript-Based Development:** Strongly typed application code.
- **Modular Architecture:** Separate directories for components, DSP logic, services, types, and views.
- **Modern Frontend:** Built with React and Vite.
- **Reusable Components:** Organized component-based application structure.
- **Modern Deployment:** Hosted on Vercel.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/vibelab-signals-laboratory.git
```

### 2. Navigate to the Project Directory

```bash
cd vibelab-signals-laboratory
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If the project requires environment variables, create a `.env` file using the example:

```bash
cp .env.example .env
```

Add the required values to your `.env` file.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal (usually):

```text
http://localhost:5173/
```
